## Notes

**Focus Areas:**
1. **Survival First** - Medicine, food, rent tracking
2. **Debt Prevention** - Warnings and alternatives
3. **Emergency Preparedness** - Fund tracking and crisis mode
4. **Accessibility** - Voice, languages, offline mode
5. **Empathy** - Supportive messaging, no shame

**Success Criteria:**
- Features must solve real problems for struggling users
- UI must be simple enough for anyone to use
- Every feature must answer: "How does this help someone struggling?"
- Measure impact through user stories, not just metrics

**Remember:**
> "Every penny counts when you're struggling. Every decision matters when resources are scarce."
